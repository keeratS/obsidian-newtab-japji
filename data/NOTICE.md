## Adaptation history

2026-10-03 — Keerat Singh, New Tab Japji: extracted the 277 transliteration/translation pairs from the 40 source sections into UTF-8 JSON. Navigation, audio links, and introductory commentary are omitted. Source spelling, punctuation, capitalization, and section grouping are retained; incidental HTML whitespace is normalized. The plugin groups these pairs into passages of at most four, or two for pauris containing paired sentences, without crossing section boundaries. No new translation was authored.

The JSON file is the transparent, editable copy of this adaptation. The release bundle includes this notice, the full license, and that JSON as a readable comment so standard Obsidian installations retain all corpus documentation.
